# Agent ID Hackathon (Binance Wallet × BNB Chain)

- Build dApps that actively use **Agent ID** (`name.ai`, the on-chain, non-transferable name of an Agentic Wallet; one per user).
- Smart contracts must be deployed on **BNB Chain**, with verified, open-source code on **BscScan**.
- New and existing projects are eligible; for existing projects only activity during the Submission Period counts.
